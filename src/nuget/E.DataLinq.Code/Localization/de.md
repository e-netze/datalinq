#general: Allgemein
#connection: Verbindung
#security: Sicherheit
#authorizedUsersRoles: Berechtigte Nutzer/Rollen
#refresh: Aktualisieren
#clear: Löschen
#info: Informationen
#submit: Absenden
#openEndpointCss: Öffne EndPoint CSS...
#openEndpointJs: Öffne EndPoint JS...
#delete: Löschen
#description_delete: Löscht diesen Endpoint, inklusieve aller queries und views ...
#description_endpoint_delete: Diesen Endpoint löschen (inklusieve aller queries und views) ...
#description_endpoint_css: Hier können Sie eine globale EndPoint-CSS-Datei bearbeiten, die in allen (Ansichts-)Berichten unter diesem EndPoint geladen wird.
#description_endpoint_js: Hier können Sie eine globale EndPoint-JavaScript-Datei bearbeiten, die in allen (Ansichts-)Berichten unter diesem EndPoint geladen wird.
#endPointId: EndPoint Id
#description_endPointId: Die eindeutige Endpunkt-ID (schreibgeschützt)
#description_endPointName: Ein aussagekräftiger Name für den Endpunkt
#endPointDescription: Beschreibung
#description_endPointDescription: Hier können Sie den Verwendungszweck des Endpunkts beschreiben
#description_endPointAccess: Fügen Sie Benutzer und Rollen hinzu oder entfernen Sie diese, die auf den Endpunkt zugreifen dürfen. Verwenden Sie * (Sternchen) als Benutzernamen, um den Zugriff auf diesen Endpunkt für alle Benutzer zu ermöglichen.
#accessTokens: Zugriffstoken
#description_accessTokens: Hier können Sie festlegen, ob der Zugriff auf den Endpunkt über Token möglich ist. Es müssen entweder beide oder keine Token festgelegt werden.
#endPointConnectionTypes: Verbindungstyp des Endpunkts
#description_endPointConnectionTypes: Hier können Sie festlegen, ob der Endpunkt auf eine Datenbank oder eine DataLINQ-Engine verweist
#conStringProd: Verbindungsstring (Standard/Produktion)
#description_conStringProd: Der Verbindungsstring zu einer Datenbank oder eine URL zu einem Dienst. Bei Klartext kann dieses Feld leer bleiben. Dieser Verbindungsstring wird verwendet, wenn die DataLinq-Umgebung auf „Standard“ oder „Produktion“ eingestellt ist oder keine DevTest-Verbindung besteht.
#conStringTest: Verbindungsstring (Entwicklung/Test)
#description_conStringTest: Der Verbindungsstring zu einer Datenbank oder eine URL zu einem Dienst. Bei Klartext kann dieses Feld leer sein. Dieser Verbindungsstring wird verwendet, wenn die DataLinq-Umgebung auf „Entwicklung“ oder „Test“ eingestellt ist.
